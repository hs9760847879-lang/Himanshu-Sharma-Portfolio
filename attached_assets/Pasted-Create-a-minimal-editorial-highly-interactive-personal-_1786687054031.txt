# 2. WEBSITE STYLE — IMPORTANT

The primary design principle is:

**Less interface. More personality. More interaction.**

Do NOT generate the usual AI portfolio structure with a hero, eight boxed sections, glowing gradients, skill badges, generic cards, or a dashboard-looking interface.

Use a **minimal editorial art-direction** inspired by high-end independent portfolios, digital studios, and product-design case studies.

Visual rules:

* Off-white, warm white, or near-black background
* One restrained accent colour only
* Large typography with strong hierarchy
* Lots of empty space
* Thin rules and subtle dividers
* Mostly flat surfaces
* Very limited rounded containers
* No unnecessary glassmorphism
* No excessive gradients
* No giant decorative illustrations
* No stock imagery
* No generic AI graphics
* No percentage badges everywhere
* No giant skill grids
* No excessive cards

Use a typography-led composition where text itself becomes part of the visual design.

The site should feel **calm at first glance, but surprisingly interactive once explored**.

Interactions should be subtle and purposeful:

* magnetic or animated text links
* project previews that respond to cursor movement
* horizontal scroll moments
* image/text transitions
* masked text reveals
* smooth page transitions
* hover-based metadata reveals
* elegant loading transitions

Motion should never feel like decoration for decoration's sake. Every interaction should help communicate the work.
